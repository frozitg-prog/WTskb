# MyScoreboard — Paper 1.21.4

Плагин для боковой панели scoreboard. Использует Java 21, Maven, Paper API и VaultAPI.

## Что показывает
- Название сервера и адрес из `config.yml`
- Ник игрока
- Онлайн / максимальное количество игроков
- Баланс через Vault (требуются Vault и совместимый экономический плагин)
- Убийства и смерти из статистики Minecraft
- Пинг

## Как получить JAR через GitHub Actions

1. Создайте новый репозиторий на https://github.com/new. Можно выбрать Private.
2. Распакуйте архив проекта на компьютере.
3. Загрузите **все файлы и папки внутри** распакованной папки в корень репозитория. Важно: папка `.github/workflows/build.yml` должна сохраниться.
   - На странице репозитория можно нажать **Add file → Upload files** и перетащить файлы/папки, либо загрузить проект через GitHub Desktop.
4. Нажмите **Commit changes**.
5. Откройте вкладку **Actions** репозитория. Workflow **Build MyScoreboard** должен запуститься автоматически.
6. Откройте завершившийся запуск с зелёной галочкой.
7. Внизу страницы запуска, в разделе **Artifacts**, нажмите **MyScoreboard**. Скачается ZIP-архив.
8. Распакуйте ZIP. Внутри будет `MyScoreboard.jar`.
9. Остановите сервер, скопируйте JAR в папку `plugins/` и запустите Paper снова.

Если автоматическая сборка не стартовала: Actions → Build MyScoreboard → Run workflow.

## Настройка
После первого запуска сервер создаст `plugins/MyScoreboard/config.yml`.
Отредактируйте `server-name`, `server-address` и `update-interval-ticks`, затем полностью перезапустите сервер.

## Требования
- Paper 1.21.4
- Java 21 на сервере
- Для реального баланса: Vault и совместимый economy provider

## Если сборка падает
Откройте запуск в Actions, нажмите на шаг `Build plugin JAR` и скопируйте первые строки с `ERROR` для диагностики.
